# Persian font (Vazirmatn)

Vazirmatn v33.0.3 by the Vazirmatn Project Authors
(https://github.com/rastikerdar/vazirmatn), bundled locally so the app
never depends on an external font CDN. Licensed under the SIL Open Font
License 1.1 — see `OFL.txt` in this directory, which must ship with the
font files.

Files and weights (declared in `resources/css/app.css`):

- `Vazirmatn-Regular.woff2` — 400
- `Vazirmatn-Medium.woff2` — 500
- `Vazirmatn-SemiBold.woff2` — 600
- `Vazirmatn-Bold.woff2` — 700
